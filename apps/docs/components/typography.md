## استفاده

```vue
<Typography variant="prose">
  <h2>عنوان بخش</h2>
  <p>محتوای متنی با فاصله‌گذاری منظم و رنگ‌های معنایی.</p>
</Typography>
```

گونه‌های `prose`، `lead`، `large`، `small`، `muted` و `inlineCode` قابل استفاده هستند.
