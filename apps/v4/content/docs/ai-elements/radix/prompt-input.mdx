Prompt Input is the field the person types into to message the agent. It is an [Input Group](/docs/components/radix/input-group) with a textarea, an attach button, the [Model Selector](/docs/ai-elements/radix/model-selector) menus and a send button. Attached files show as [Attachment](/docs/components/radix/attachment) chips above the text.

## Installation

Prompt Input is built with the [Input Group](/docs/components/radix/input-group), [Attachment](/docs/components/radix/attachment) and [Dropdown Menu](/docs/components/radix/dropdown-menu) components.

## Inline Tokens

Use `PromptInputEditor` in place of the textarea to add skill and mention suggestions. Type `/` or `@`, filter the list, then choose an item with the arrow keys and Enter or with the mouse. Escape dismisses the list. Enter sends the message through `onSubmit`; Shift+Enter inserts a new line.

<ComponentPreview
  styleName="radix-rhea"
  name="prompt-input-tokens"
  previewClassName="h-auto"
/>

```bash
npx shadcn@latest add prompt-input
```

```tsx showLineNumbers
import type { PromptInputValue } from "@shadcn/react/prompt-input"
import {
  PromptInputContent,
  PromptInputEditor,
} from "@/components/ui/prompt-input"

const [value, setValue] = React.useState<PromptInputValue>({
  text: "",
  tokens: [],
})

<PromptInputEditor
  aria-label="Message"
  value={value}
  onValueChange={setValue}
  suggestions={[
    { type: "skill", id: "review", trigger: "/", label: "review" },
    { type: "file", id: "readme", trigger: "@", label: "README.md" },
  ]}
  onSubmit={() => sendMessage(value)}
/>
```

Only items chosen from the suggestions become tokens. Backspace or Delete removes a selected token as a unit. Typing or pasting `/review` leaves ordinary text. Copy and paste use plain text, so pasted tokens become editable text too.

The value includes `text` and a `tokens` array. Each token has `type`, `id`, `trigger`, `label`, `start` and `end`. Positions are UTF-16 offsets into `text`, with an exclusive `end`. Text includes each token's trigger and label. For example, choosing `review` produces `{ text: "/review ", tokens: [{ type: "skill", id: "review", trigger: "/", label: "review", start: 0, end: 7 }] }`. Tokens remain separate even when the same item appears more than once, and their positions update as text is edited.

Pass the saved value to `PromptInputContent` inside a message to render the same tokens. Both components accept `renderToken` for a custom badge or chip:

```tsx
const renderToken = (token) => (
  <Badge variant="secondary">{token.trigger}{token.label}</Badge>
)

<PromptInputEditor renderToken={renderToken} /* ... */ />
<PromptInputContent value={message} renderToken={renderToken} />
```

Token renderers should return non-interactive inline content. The editor owns keyboard focus and selection. Use `defaultValue` for an uncontrolled editor, or `value` and `onValueChange` to control it. Replacing a controlled value resets editing history, so clearing a sent message does not restore it on Undo. `disabled` and `readOnly` prevent editing and suggestions.

The token editor uses Lexical for editing, selection and undo. It is an optional peer dependency of `@shadcn/react`; installing `prompt-input` adds `lexical` and `@lexical/react` to your project. The textarea composition above does not need them.

## Attachments

The attach button opens a hidden file input. Show each file as an [Attachment](/docs/components/radix/attachment) in an addon with `align="block-start"`, with a button to remove it.

## Model and Effort

Put the two [Model Selector](/docs/ai-elements/radix/model-selector) menus in the `block-end` addon, between the attach and send buttons. Move `ml-auto` from the send button to the first menu trigger, so both menus sit next to the send button.

## Keyboard

Enter sends the message. Shift+Enter adds a new line.

```tsx showLineNumbers
onKeyDown={(event) => {
  if (event.key === "Enter" && !event.shiftKey) {
    event.preventDefault()
    formRef.current?.requestSubmit()
  }
}}
```

## AI SDK

Send the text and the `FileList` from the file input.

```tsx showLineNumbers
sendMessage({ text, files })
```

The route streams the reply with `result.toUIMessageStreamResponse()`.

## Migrating from AI SDK Elements

If you added Prompt Input from [AI SDK Elements](https://elements.ai-sdk.dev), your project has a `components/ai-elements/prompt-input.tsx` wrapper. Paste this prompt into your coding agent to rebuild it on Input Group and Attachment. Every export keeps its name and props, so the code that uses it keeps working.

```txt title="Prompt" prompt
Migrate components/ai-elements/prompt-input.tsx from AI SDK Elements to the shadcn/ui Input Group and Attachment components.

Keep every export, with the same name and props, so the code that imports it keeps working. Only change how each part renders.

1. Install the components: npx shadcn@latest add input-group attachment
2. Read https://ui.shadcn.com/docs/ai-elements/radix/prompt-input.md and build Prompt Input the same way.
3. Rebuild each part:
   - PromptInput already renders an Input Group. Keep the form, the provider, the attachment state and the command parts as they are.
   - PromptInputTextarea renders an InputGroupTextarea with className="p-3".
   - PromptInputActionMenuTrigger renders an InputGroupButton with size="icon-sm", variant="outline" and rounded-full, with a PlusIcon.
   - PromptInputSubmit renders an InputGroupButton with size="icon-sm", variant="default" and rounded-full, with an ArrowUpIcon while idle. Keep the spinner and stop icons for the other statuses.
   - PromptInputHeader shows each attachment as an Attachment with size="sm" and a button to remove it.
   - Keep PromptInputSelect, PromptInputHoverCard and the tab parts as they are.
4. Remove the imports the file no longer uses.
5. Run the type checker and fix any errors.
```
