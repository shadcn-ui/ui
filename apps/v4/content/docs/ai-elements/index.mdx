AI Elements are patterns for building agentic interfaces. Each one is a composition of shadcn/ui components that you copy into your project. There is no package to install. The code is yours.

A [Chat](/docs/ai-elements/base/chat) is a list of [Message](/docs/ai-elements/base/message) turns inside a [Message Scroller](/docs/components/base/message-scroller). The steps an agent takes inside a turn, like [Reasoning](/docs/ai-elements/base/reasoning), [Tool](/docs/ai-elements/base/tool) and [Plan](/docs/ai-elements/base/plan), are built on [Trace](/docs/components/base/trace), so every step has the same shape.

**Coming from [elements.ai-sdk.dev](https://elements.ai-sdk.dev)?** See [Migrating from AI SDK Elements](#migrating-from-ai-sdk-elements).

## Migrating from AI SDK Elements

If you used AI SDK Elements from [elements.ai-sdk.dev](https://elements.ai-sdk.dev), here is what changes.

### Existing projects

You do not need to migrate. When you installed components from elements.ai-sdk.dev, the code was copied into your project. It is yours, and it keeps working as is.

To move a wrapper onto shadcn/ui components, use the prompt in the **Migrating from AI SDK Elements** section of its pattern page. Paste it into your coding agent. It rebuilds the file in `components/ai-elements` on Trace, Code Block and the other shadcn/ui components, and keeps every export and its props, so the code that uses it does not change.

For example, the [Queue](/docs/ai-elements/base/queue#migrating-from-ai-sdk-elements) prompt rebuilds `queue.tsx` on Trace, and the [Inline Citation](/docs/ai-elements/base/inline-citation#migrating-from-ai-sdk-elements) prompt rebuilds `inline-citation.tsx` on Hover Card.

### Elements without a replacement

We did not rebuild these elements. We looked at how often each one is used, and the numbers are low. Each one is also a small composition you can build from components shadcn/ui already has, listed below.

Your copy keeps working. If you still need one of these, [open an issue](https://github.com/shadcn-ui/ui/issues/new?template=feature_request.yml) and we will help you build it.

### New projects

Build from shadcn/ui components instead.

<Step>Add the components</Step>


<Step>Copy a pattern</Step>

Or ask your coding agent to do it:

