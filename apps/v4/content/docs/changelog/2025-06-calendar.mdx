We've upgraded the `Calendar` component to the latest version of [React DayPicker](https://daypicker.dev).

This is a major upgrade and includes a lot of new features and improvements.

<Image src="/images/calendar-2.png" alt="Calendar" width={676} height={895} />

To upgrade your project to the latest version of the `Calendar` component, run the following command:

```bash
npx shadcn@latest add calendar
```

When you're prompted to overwrite the existing `Calendar` component, select `Yes`. If you've made changes to your `Calendar` component, you'll need to merge them with the new version.

Then follow the [React DayPicker upgrade guide](https://daypicker.dev/v9/upgrading) to upgrade any other code that uses React DayPicker.
