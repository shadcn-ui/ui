---
title: November 2026 - Base Ripple Buttons
description: Choose the pressed or ripple interaction for the default Button.
date: 2026-11-16
---

You can now choose the default `Button` active style when creating or initializing a project:

```bash
npx shadcn@latest init --button-active-style ripple
```

Choose `default`, `ripple`, or `ripple-blur`. Ripple styles install `@base-ripple/react`, add its stylesheet, and save `buttonActiveStyle` in `components.json`. The default Button keeps the same import and props, and ripple styles remove its pressed movement.
