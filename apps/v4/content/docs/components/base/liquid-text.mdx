## API Reference

### LiquidText

The `LiquidText` component displays text with an interactive liquid displacement effect.

| Prop          | Type     | Default                 |
| ------------- | -------- | ----------------------- |
| `text`        | `string` | `"Liquid Text"`         |
| `fontSize`    | `number` | `200`                   |
| `font`        | `string` | `"Inter, sans-serif"`   |
| `color`       | `string` | -                       |
| `lightColor`  | `string` | `"#000000"`             |
| `darkColor`   | `string` | `"#ffffff"`             |
| `className`   | `string` | -                       |
