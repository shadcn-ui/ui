## Usage

```tsx showLineNumbers
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"
```

```tsx showLineNumbers
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Are you absolutely sure?</DialogTitle>
      <DialogDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

## Composition

Use the following composition to build a `Dialog`:

```text
Dialog
├── DialogTrigger
└── DialogContent
    ├── DialogHeader
    │   ├── DialogTitle
    │   └── DialogDescription
    └── DialogFooter
```

## Custom Close Label

Use `closeLabel` to customize the label announced by the dialog close button. This is useful when the default `"Close"` label needs to be localized or customized.

```tsx showLineNumbers
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent closeLabel="Dismiss">
    <DialogHeader>
      <DialogTitle>Custom close label</DialogTitle>
      <DialogDescription>
        The close button uses the provided label.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

When using the optional footer close button, the same prop controls its visible label:

```tsx showLineNumbers
<DialogFooter showCloseButton closeLabel="Cancel">
  <Button>Save changes</Button>
</DialogFooter>
```

The default value for `closeLabel` is `"Close"`.

## API Reference

### DialogContent

In addition to the underlying Base UI `Dialog.Popup` props, `DialogContent` supports the following props:

| Prop               | Type      | Default  | Description                                                   |
| ------------------ | --------- | -------- | ------------------------------------------------------------- |
| `showCloseButton`  | `boolean` | `true`   | Whether to render the default close button.                   |
| `closeLabel`       | `string`  | `"Close"` | Accessible label for the default close button.               |

### DialogFooter

`DialogFooter` supports the following props in addition to standard `<div>` props:

| Prop               | Type      | Default  | Description                                      |
| ------------------ | --------- | -------- | ------------------------------------------------ |
| `showCloseButton`  | `boolean` | `false`  | Whether to render a close button in the footer. |
| `closeLabel`       | `string`  | `"Close"` | Label displayed by the footer close button.     |

See the [Base UI Dialog documentation](https://base-ui.com/react/components/dialog#api-reference) for the underlying Dialog API.
