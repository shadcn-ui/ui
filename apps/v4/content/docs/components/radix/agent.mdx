Use Agent when the assistant hands work to a sub-agent. The run is one row. Open it to see the sub-agent's own tool calls and what it found.

It is the shadcn/ui version of Agent from [AI Elements](https://ai-sdk.dev/elements/overview). Instead of a component of its own, it is a composition of [Trace](/docs/components/radix/trace), so it looks and behaves like every other row in the conversation.

## Usage

```tsx showLineNumbers
import {
  Trace,
  TraceCollapsible,
  TraceCollapsibleContent,
  TraceCollapsibleTrigger,
  TraceIcon,
  TraceLine,
  TraceTitle,
} from "@/components/ui/trace"
```

```tsx showLineNumbers
<Trace>
  <TraceCollapsible>
    <TraceCollapsibleTrigger>
      <TraceLine>
        <TraceIcon>
          <BotIcon />
        </TraceIcon>
        <TraceTitle>Ran the research agent</TraceTitle>
      </TraceLine>
    </TraceCollapsibleTrigger>
    <TraceCollapsibleContent className="flex flex-col gap-3">
      <Trace>
        <TraceLine>
          <TraceIcon>
            <SearchIcon />
          </TraceIcon>
          <TraceTitle>Searched the web for next.js image cache key</TraceTitle>
        </TraceLine>
      </Trace>
      <p>The image cache is keyed on the commit hash.</p>
    </TraceCollapsibleContent>
  </TraceCollapsible>
</Trace>
```

## AI SDK

With the AI SDK, a sub-agent is a tool whose `execute` yields the sub-agent's `UIMessage` as it streams. Render the tool part as the row and `part.output.parts` as the nested `Trace`.

Map the tool part as in [Tool](/docs/components/radix/tool#states).

| Tool part state                             | `status`    | Title     |
| ------------------------------------------- | ----------- | --------- |
| `output-available` with `preliminary: true` | `"running"` | Running … |
