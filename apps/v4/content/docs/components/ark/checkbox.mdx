## Usage

The `Checkbox` component renders the control, indicator, and hidden input internally. Pass children to add a label.

```tsx
import { Checkbox } from "@/components/ui/checkbox"
```

```tsx
<Checkbox>Accept terms and conditions</Checkbox>
```

## Checked State

Use `defaultChecked` for uncontrolled checkboxes, or `checked` and `onCheckedChange` to control the state.

```tsx showLineNumbers
import * as React from "react"

import {
  Checkbox,
  type CheckboxCheckedChangeDetails,
} from "@/components/ui/checkbox"

export function Example() {
  const [checked, setChecked] = React.useState(false)

  return (
    <Checkbox
      checked={checked}
      onCheckedChange={(details: CheckboxCheckedChangeDetails) =>
        setChecked(!!details.checked)
      }
    >
      Accept terms
    </Checkbox>
  )
}
```

## API Reference

### Checkbox

`Checkbox` is a closed composition: it renders `Checkbox.Control`, both
indicators and `Checkbox.HiddenInput` internally, and wraps any children in
`Checkbox.Label`. Passing your own control as children renders a second one.
Every prop is forwarded to `Checkbox.Root`.

| Prop              | Type                                                         | Default | Description                                       |
| ----------------- | ------------------------------------------------------------ | ------- | ------------------------------------------------- |
| `checked`         | `boolean \| "indeterminate"`                                 | —       | Controlled checked state.                         |
| `defaultChecked`  | `boolean \| "indeterminate"`                                 | —       | Initial state when uncontrolled.                  |
| `onCheckedChange` | `(details: { checked: boolean \| "indeterminate" }) => void` | —       | Called with a details object, not a bare boolean. |
| `disabled`        | `boolean`                                                    | `false` | Disable the checkbox.                             |
| `readOnly`        | `boolean`                                                    | `false` | Render but don't accept input.                    |
| `invalid`         | `boolean`                                                    | `false` | Show invalid styles.                              |
| `required`        | `boolean`                                                    | `false` | Mark required for form validation.                |
| `name`            | `string`                                                     | —       | Name of the hidden input.                         |
| `value`           | `string`                                                     | —       | Value submitted with a form.                      |
| `form`            | `string`                                                     | —       | Id of the form to associate with.                 |

### Composed parts

For layouts the closed component can't express, build it yourself from
`CheckboxRoot`, `CheckboxControl`, `CheckboxIndicator`, `CheckboxLabel` and
`CheckboxHiddenInput`. Use these _instead of_ `Checkbox`, never inside it.

See the [Ark UI Checkbox](https://ark-ui.com/docs/components/checkbox#api-reference) documentation for the complete reference.
