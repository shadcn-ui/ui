An assistant does more than write text. It thinks, searches, reads files, runs commands and calls tools, and each of those needs a place in the conversation. Most chat UIs build a component for each one: a reasoning panel, a tool card, a sources list, a task list. Each ends up with its own shape, its own chevron and its own idea of what "running" looks like.

To fix this, we created `Trace`. Each of those is one line: an icon, a sentence that says what happened, and an optional status. When there is more to see, the line expands, links out or opens a sheet. Reasoning, tool calls, sources and plans are all compositions of the same few parts.

Use `Trace` for what the assistant did. Use [Message](/docs/components/aria/message) for what it said, and [Marker](/docs/components/aria/marker) for notes and dividers between turns.

## Usage

```tsx showLineNumbers
import {
  Trace,
  TraceCollapsible,
  TraceCollapsibleContent,
  TraceCollapsibleTrigger,
  TraceIcon,
  TraceLine,
  TraceTitle,
} from "@/components/ui/trace"
```

```tsx showLineNumbers
<Trace>
  <TraceLine>
    <TraceIcon>
      <SearchIcon />
    </TraceIcon>
    <TraceTitle>Searched for minimumReleaseAge</TraceTitle>
  </TraceLine>
  <TraceCollapsible>
    <TraceCollapsibleTrigger>
      <TraceLine>
        <TraceIcon>
          <TerminalIcon />
        </TraceIcon>
        <TraceTitle>Ran node --version</TraceTitle>
      </TraceLine>
    </TraceCollapsibleTrigger>
    <TraceCollapsibleContent>v24.18.0</TraceCollapsibleContent>
  </TraceCollapsible>
</Trace>
```

## Composition

```text
Trace
├── TraceLine
│   ├── TraceIcon
│   ├── TraceTitle
│   ├── TraceDescription
│   └── TraceIcon
├── TraceCollapsible
│   ├── TraceCollapsibleTrigger
│   │   └── TraceLine
│   └── TraceCollapsibleContent
└── A link, Sheet or Dialog
    └── The anchor or trigger
        └── TraceLine
```

`TraceLine` is always the line. To make a line do something, wrap it in that thing's trigger.

## Features

- **It reads as one sentence.** A `TraceLine` is an icon and a title on one line. The title truncates. A `TraceDescription` holds a count or a duration and does not.
- **It stays quiet.** Rows are muted text with no border or background, so they sit between paragraphs without competing with the answer.
- **It leaves behavior to the wrapper.** Wrap the line in a collapsible trigger, a link, or the trigger of a Dialog, Sheet, Drawer or Popover. The trigger stays a real button or anchor.
- **It shows status without extra UI.** `"running"` shimmers the title, `"error"` turns the row destructive and `"pending"` fades it.
- **It nests.** A collapsible row can hold another `Trace`, so a summary expands into steps and a step expands into its output.
- **It maps to the AI SDK.** Reasoning, tool and source parts each render as a row. See [Thinking](#thinking) and [Tool Calls](#tool-calls).

| Status      | Use for                                                                       |
| ----------- | ----------------------------------------------------------------------------- |
| none        | Work that is done: "Ran pnpm install".                                        |
| `"error"`   | Work that failed. Say so in the title: "Failed to run pnpm lint".             |
| `"running"` | Work in progress. Write the title in the present tense: "Running pnpm build". |
| `"pending"` | Work that has not started, such as a plan step: "Run pnpm test".              |

## Open State

Rows start closed. Use `defaultExpanded` on `TraceCollapsible` to start open, or `isExpanded` with `onExpandedChange` to control a row.

<ComponentPreview
  styleName="aria-rhea"
  name="trace-open"
  previewClassName="h-auto"
/>

To open a row while it streams and let the reader's click win, pass `open ?? running`.

```tsx showLineNumbers
const [open, setOpen] = React.useState<boolean>()

<TraceCollapsible
  isExpanded={open ?? running}
  onExpandedChange={setOpen}
>
  <TraceCollapsibleTrigger>
    <TraceLine status={running ? "running" : undefined}>…</TraceLine>
  </TraceCollapsibleTrigger>
  <TraceCollapsibleContent>{text}</TraceCollapsibleContent>
</TraceCollapsible>
```

## Accessibility

`Trace` adds no roles of its own. Each row gets its semantics from the element that wraps its `TraceLine`.

- A `TraceLine` on its own is a `span`. It is read as text and is not a tab stop.
- A collapsible row's `TraceCollapsibleTrigger` is a button with `aria-expanded`. A link row is the anchor, and an overlay row is the button that opens the overlay, so keyboard and focus behavior come from that element.
- `TraceIcon` is hidden from assistive tech, so the `TraceTitle` is the accessible name. Write it as a full sentence. For a link that opens a new tab, add sr-only "(opens in a new tab)" to the title.
- `Trace` carries no list roles. Inside a [Message Scroller](/docs/components/aria/message-scroller), each row is announced once when it is added.
- The shimmer on a running title stops when the reader prefers reduced motion. The tense of the title, such as "Running pnpm build", still says the row is running.
- `TraceCollapsibleContent` mutes its text. Give a block with a muted background inside it `text-foreground` so it keeps its contrast. `CodeBlock` sets its own text color.

## API Reference

### Trace

A list of rows. It also styles any trigger or link that wraps a `TraceLine`.

| Prop        | Type     | Default | Description                              |
| ----------- | -------- | ------- | ---------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the list. |

### TraceLine

One line: an icon and a title. It is a span, so it is not a button or a tab stop. Wrap it in a trigger or a link to make it do something.

| Prop        | Type                                | Default | Description                                                            |
| ----------- | ----------------------------------- | ------- | ---------------------------------------------------------------------- |
| `status`    | `"running" \| "error" \| "pending"` | -       | The state of the work the line reports. Omit it when the work is done. |
| `className` | `string`                            | -       | Additional classes to apply to the line.                               |

### TraceIcon

A decorative icon slot, hidden from assistive tech. Before the title it names the action; after it, it is the indicator.

| Prop        | Type     | Default | Description                                   |
| ----------- | -------- | ------- | --------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the icon slot. |

### TraceTitle

One sentence on one line. It truncates and shimmers while the line is running.

| Prop        | Type     | Default | Description                               |
| ----------- | -------- | ------- | ----------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the title. |

### TraceDescription

Secondary text after the title, such as a count or a duration. It does not truncate.

| Prop        | Type     | Default | Description                                     |
| ----------- | -------- | ------- | ----------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the description. |

### TraceCollapsible

A row that expands. It accepts the props of [`Collapsible`](/docs/components/aria/collapsible). `className` takes a string only.

| Prop               | Type                            | Default | Description                                                 |
| ------------------ | ------------------------------- | ------- | ----------------------------------------------------------- |
| `isExpanded`       | `boolean`                       | -       | The controlled open state. Pass it with `onExpandedChange`. |
| `defaultExpanded`  | `boolean`                       | `false` | Whether the row starts open.                                |
| `onExpandedChange` | `(isExpanded: boolean) => void` | -       | Called when the open state changes.                         |
| `className`        | `string`                        | -       | Additional classes to apply to the row.                     |

### TraceCollapsibleTrigger

The button that opens and closes the row. Put a `TraceLine` inside it. It adds a chevron after the line.

| Prop        | Type     | Default | Description                                 |
| ----------- | -------- | ------- | ------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the trigger. |

### TraceCollapsibleContent

The detail of a row that expands.

| Prop        | Type     | Default | Description                                 |
| ----------- | -------- | ------- | ------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the content. |
