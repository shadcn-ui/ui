Use Commit to show a commit the assistant made. The commit message is the row. Open it for the changed files and their diffs.

It is the shadcn/ui version of Commit from [AI Elements](https://ai-sdk.dev/elements/overview). Instead of a component of its own, it is a composition of [Trace](/docs/components/aria/trace), so it looks and behaves like every other row in the conversation.

## Usage

```tsx showLineNumbers
import {
  Trace,
  TraceCollapsible,
  TraceCollapsibleContent,
  TraceCollapsibleTrigger,
  TraceDescription,
  TraceIcon,
  TraceLine,
  TraceTitle,
} from "@/components/ui/trace"
```

```tsx showLineNumbers
<Trace>
  <TraceCollapsible>
    <TraceCollapsibleTrigger>
      <TraceLine>
        <TraceIcon>
          <GitCommitHorizontalIcon />
        </TraceIcon>
        <TraceTitle>Committed a1b2c3: Fix the login redirect</TraceTitle>
      </TraceLine>
    </TraceCollapsibleTrigger>
    <TraceCollapsibleContent>
      <Trace>
        <TraceLine>
          <TraceIcon>
            <FilePenIcon />
          </TraceIcon>
          <TraceTitle>Edited app/login/page.tsx</TraceTitle>
          <TraceDescription className="font-mono">+12 −3</TraceDescription>
        </TraceLine>
      </Trace>
    </TraceCollapsibleContent>
  </TraceCollapsible>
</Trace>
```

## Files

Each changed file is a `TraceLine`. Say what changed in the title and pick the icon to match.

| Change  | Title     | Icon            |
| ------- | --------- | --------------- |
| Added   | Added …   | `FilePlusIcon`  |
| Edited  | Edited …  | `FilePenIcon`   |
| Deleted | Deleted … | `FileMinusIcon` |

## Diff

Wrap a file line in React Aria's `Button` inside a `SheetTrigger` to open its diff. Add a chevron-right `TraceIcon` at the end of the line.

Render a commit tool part. Map the tool part as in [Tool](/docs/components/aria/tool#states), with the verbs Committing, Committed and Failed to commit.
